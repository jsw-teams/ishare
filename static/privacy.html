隐私与分享

发布需要 GitHub 登录。本站保存 GitHub 数字用户 ID、用户名与显示名称以确认发布与删除权限，不索取 GitHub 邮箱或代码仓库权限。GitHub 身份不代表已核实来源网站所有权。

图片、视频、标题、配文、作者与填写的来源页面会公开显示。请勿上传没有分享权利或包含不应公开信息的媒体。浏览者可以下载或另行转载公开内容。

媒体存储与编码由 Cloudflare Images / Stream 处理。上传文件时，浏览器会向 Cloudflare 的一次性上传地址发送媒体和必要网络信息；分享与播放使用本站媒体地址。

登录凭据使用安全的 HttpOnly Cookie，最长一天，到期或退出后失效。OAuth 状态最长十分钟且只能使用一次。服务为限制滥用使用短期哈希限流记录，不将 IP 原值保存为公开媒体资料。未完成的已知上传保留至清理任务删除，通常在一天后清理；无法确认上游是否完成的上传需管理员核对。

发布者可在媒体列表删除自己发布的内容。管理员可以移除违规内容。已缓存的公开媒体最长还可能显示五分钟；其他网站自行保存的副本不受本站控制。每日限额所需的删除记录最多保留三十天，不保留媒体字节。管理记录与已答复隐私请求最长保存九十天；账户删除完成时会提前清除关联个人资料。

额度按图片存储张数、每月图片传递次数、视频储存时长与每月视频传递时长分别计算；图片传递次数与视频传递时长用于后台用量统计，不设置常规传递额度；预加载和重复请求也会记入统计。降低额度或普通暂停需要明确原因并提前七天站内通知，紧急滥用可立即暂停新上传、发布或公开分享，均不会自动删除既有媒体，仍保留申诉和本人资料权利入口。暂停发布仍可导出 JSON 资料、删除本人媒体或账户、申请更正及人工复核。导出不包含原始视频文件。

隐私请求在后台显示一个日历月的答复期限，需要运营者实际处理。账户删除会立即停止已知媒体的公开访问，随后删除上游媒体、账户与关联个人记录；上游失败会重试，无法确认的上传需人工核对。未完成时会标为正在删除，不自动认定删除成功。

为提供你请求的登录、发布与分享服务，我们处理必要的身份与媒体资料；最小限度的限流和管理记录用于防止滥用。GitHub 与 Cloudflare 按各自政策处理必要网络信息，服务可能在全球节点处理数据。你可要求查阅、更正、删除或限制处理、提出异议，并联系适用的数据保护监管机构。运营者需要依据适用地区法律履行告知、供应商安排与权利请求处理义务。

本机只保存语言选择，不含广告或统计追踪。嵌入网站应在访客同意且请求查看后加载本站媒体。

管理者：JS.GRIPE。隐私与内容移除请求请在登录后的“我的数据与权利”提交，或邮件联系 helper@js.gripe，无需在公开问题页提供私人资料。

ishare uses your numeric GitHub identity, username and display name for publishing and ownership. Published media and attribution are public. Files upload directly to Cloudflare; viewing uses this site's proxy. Session cookies expire after one day, OAuth state after ten minutes. You can delete your own media; cached copies can remain for up to five minutes. Public media can be downloaded and copied. Storage quotas distinguish image counts and stored video duration; image deliveries and delivered segment duration are monitored without ordinary viewer quotas. Ordinary reductions are announced seven days in advance; urgent abuse restrictions do not remove export, deletion or appeal rights. Account erasure stops known public media, removes provider resources and then scrubs personal records; failed removals remain pending. Privacy requests have a calendar-month response deadline and need actual operator review. Identifiable administration and answered request records expire after ninety days, earlier on completed account erasure. Contact JS.GRIPE at helper@js.gripe. No advertising or analytics are included.
